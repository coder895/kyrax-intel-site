# KYRAX Intel — beta front door

The public landing page for KYRAX Intel, served by GitHub Pages.

**This repo is public and contains no data and no app code** — only a single static
`index.html`. The platform itself (auth, permit search, the contact gate) is a Node app in
the private `kyrax-intel-public` repo and runs on its own VPS behind a login wall. Nothing
that touches permit records, business contacts, or customer data belongs in this repo.

The page is `noindex, nofollow` on purpose: the beta is invite-only and dark
(BETA-PLAN §1). Remove that meta tag when the Phase-2 gates are met, not before.

Coverage figures are the recent 90-day average and go stale. Re-check them against the
snapshot before quoting them to anyone.
